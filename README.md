# Casandra

Casandra is a Unity project organized around explorable scenes, shared assets, first-person controls, and reusable project resources.

## Technology

- Unity 6.0.4.11f1
- Scene-based Unity project
- First-person controller assets
- TextMeshPro resources
- Shared meshes, prefabs, textures and shaders

## Scene areas

- Cockpit
- Garden
- Oasis
- Terminal

## Getting started

1. Install Unity 6.0.4.11f1.
2. Clone the repository.
3. Open the root folder through Unity Hub.
4. Allow Unity to import packages and assets.
5. Open a scene under Assets/Scenes/.
6. Enter Play Mode.

## Development notes

Keep Unity-generated files out of version control where appropriate. Preserve .meta files for tracked assets and keep reusable gameplay logic under Assets/SharedAssets/Scripts/.

This change adds documentation only; no gameplay behavior was fabricated.
